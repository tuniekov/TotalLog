TotalLog — журнал запросов MODX
================================

Логирует ВСЕ запросы, которые обрабатывает MODX: кто, что, откуда, чем
закончилось, сколько выполнялось и во сколько запросов к базе обошлось.
Плагин работает на OnMODXInit, поэтому в журнал попадают и запросы к API, и
обработчики компонентов, и старый код мимо API, и запуски из консоли.

Две задачи
----------
1. Кто что изменил.
2. Какую нагрузку и откуда создают запросы: время выполнения, число SQL и
   время в базе, страница-источник.

Кто что сделал — без сисадмина
------------------------------
Кроме админского журнала есть пользовательский интерфейс: начальник отдела сам
смотрит, что делали в его участке, не дёргая администратора. Записи он видит не
в виде «POST /api/…», а человеческим текстом.

Расшифровку делает сниппет-анализатор — он вызывается в момент записи и
превращает запрос в осмысленное описание. Под свои задачи: склонируйте
анализатор, опишите в нём свои действия, укажите имя копии в настройке
totallog_analyzer_snippet и заведите нужные доп. поля в gtsAPI — журнал начнёт
показывать ваши сущности отдельными колонками.

Что в записи
------------
Пользователь и IP, URL, метод, действие, компонент и таблица, страница-источник
ссылкой, REQUEST и тело запроса (пароли и токены маскируются, крупные тела
обрезаются), исход с причиной отказа, длительность, число SQL и время в базе,
id соединения MySQL с окном времени — для разбора по бинлогу, если он включён.

Шум выключается отдельно: служебные действия (просмотры, автодополнения) и
процессоры менеджера MODX — каждое своим рубильником со списком масок. Срок
хранения задаётся в днях, чистка идёт сама. GET по умолчанию не пишется.

Требования
----------
MODX Revolution 2.8, PHP 7.4+, MySQL 5.7+, компонент gtsAPI.

После установки
---------------
Страницы журнала создаются только на сайтах, перечисленных в конфигурации
пакета, — на вашем сайте их нужно создать самому и вставить вызов:

  [[!mixVue? &app=`totallog` &config=`{"module":"TLAll"}`]]

Модуль TLAll — админский журнал, TLUser — пользовательский (принимает список
компонентов, которые показывать). Права раздаются шаблоном политик MODX
TotalLogTemplate: totallog_view — пользовательский журнал, totallog_admin —
админский. Своих групп пользователей пакет не создаёт.

Исходники и документация: https://github.com/tuniekov/TotalLog
